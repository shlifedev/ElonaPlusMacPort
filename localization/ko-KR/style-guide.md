# ElonaPlus 2.335 한국어 번역 지침

이 지침은 2026-11-18 사용자의 한국어 번역 요청에 따라 만든다. 기준은 사용자 소유 ElonaPlus **2.335**이며, 원작 Elona 1.16 한국어 사전은 참고 자료다. Elona Mobile·Elin의 고유 번역과 설정을 자동으로 가져오지 않는다.

## 원문과 용어 선택

1. 현재 2.335의 **실제 일본어 문맥·게임 동작**을 우선하고 영어를 대조한다. 영어가 더 상세해도 일본어에 없는 설정이나 효과를 무단으로 확정하지 않는다.
2. 같은 원문이라도 화자·아이템·기술·화면이 다르면 별도 문맥으로 관리한다. 기존 한글 사전의 정규식은 그대로 실행하지 않는다.
3. `glossary.tsv`의 `ko`가 현재 채택안이다. `legacy_aliases`는 검색·이전 표기 비교용이며 함께 출력하지 않는다. 용어 변경은 해당 용어 전체를 검색해 일관되게 반영한다.
4. 원문 오류가 있는 영어 문구는 그 오류를 한국어에 복제하지 않는다. 예: `Vanish`의 일본어는 `退却`이므로 **퇴각**이다. 현재 `Welcome traveler...`는 일본어에서 종족별 장비 부위 제한 안내이므로 구판 인사말 번역을 재사용하지 않는다.
5. 영문만 있는 문구, 동적으로 조립되는 문장, 의미가 충돌하는 키는 추측한 전역 치환을 넣지 않는다. 원문을 표시하고 문맥 키가 생긴 뒤 번역한다.

## 문체

- **메뉴·목록:** 짧은 명사 또는 행동명. `장비`, `살펴보기`, `저장하고 종료`. 같은 동작의 명칭을 화면마다 바꾸지 않는다.
- **시스템 기록·설명:** 간결한 평서형 `~다`. 같은 주어가 반복되면 자연스럽게 생략한다. 원문이 실제 플레이어 행동을 가리킬 때만 `당신`을 쓴다.
- **캐릭터 생성 화면:** 인물이 말풍선으로 말하는 장면이 아닌 안내·오류·선택 설명은 모두 무인칭 서술체 `~다`로 통일한다. `종족에 따라 … 주의해야 한다.`, `결정 키를 누르면 …할 수 있다.`, `그 이름을 쓰는 모험가가 이미 있다.`처럼 쓴다. 구판 사전의 안내자 흉내 `자네/~하게`나 해체 `~해/~있어`를 이 화면에 섞지 않는다.
- **확인 창:** `~하시겠습니까?`, 결과·오류 안내는 `~할 수 없습니다.`. 개발자용 CP932·VM·해시 같은 용어를 일반 게임 문구에 넣지 않는다.
- **대사:** 화자의 태도와 장면을 먼저 확인한다. 로미아스는 능청스럽고 약 올리는 말투(`자네`, `~하게`), 라네이레는 차분하고 자연스러운 존대가 기본이다. 권력 관계·친밀도·원문의 말투 변화가 있으면 장면에 맞춘다.
- **신의 말투:** 에헤카틀의 짧은 반복과 고양이 울음, 쿠미로미의 뜸 들이는 말투 등 특징을 보존한다. 모든 신에게 일괄적인 장엄체를 쓰지 않는다.
- **작품의 유머:** 냉소, 부조리, 잔혹한 농담과 의도적인 어색함은 살린다. 번역자의 인터넷 유행어·해설·농담을 추가하지 않는다. 원문의 성적·폭력적 의미를 다른 의미로 순화하거나 확대하지 않는다.
- 말줄임표는 `…`, 문장부호는 한국어 관례를 따른다. 단, 코드가 해석하는 기호와 레이아웃 공백은 별도로 보존한다.

## 중요한 용어 구별

| 구별 | 채택 기준 |
|---|---|
| Life / HP / Mana / MP | 생명력은 능력, HP는 현재 체력 수치. 마나는 능력 또는 자원명, MP는 표시 수치. 모두 하나로 합치지 않는다. |
| Strength / Constitution / Dexterity | 근력 / 내구 / 기교. DEX를 속도·회피와 같은 개념으로 번역하지 않는다. |
| skill / spell / feat | 기술 / 주문 / 특성. 주문 사용 능력 `Casting`은 시전, `Magic Device`는 마도구. |
| mutation / Mutant race | 일반 변화는 돌연변이, 선택 종족 `カオスシェイプ`은 카오스 셰이프. |
| Juere / Jure | 종족은 주아(문장에서는 주아족), 신은 치유의 주아. 영어 식별자 Juere/Jure는 그대로 둔다. |
| material | 제작 재료, 장비 재질, 원료의 의미를 문맥으로 구별한다. |
| weight | 몸은 체중, 아이템은 무게. 동일 영어 `Weight`를 무조건 몸무게로 치환하지 않는다. |
| ally / pet | 게임 파티 구성원은 동료. 실제 반려동물을 가리키는 대사에서만 반려동물·애완동물을 사용한다. |
| curse / corruption / Ether disease | 저주 / 문맥별 오염·침식 / 에테르병을 구별한다. `cure corruption` 아이템은 일본어 근거상 에테르 항체다. |
| food hunger / starvation / burden | 배고픔·기아·굶어 죽는 중과 짐 무게로 인한 압박·짓눌림을 단계별로 구별한다. |

고유명은 기존 한국어 관용을 가능한 한 유지한다: 이에르스, 에우데르나, 베르니스, 팔미아, 데르피, 요우윈, 카풀 항, 로미아스, 에헤카틀, 룰위, 마니, 오파토스, 쿠미로미. 라네이레·이츠파로틀·야카테크트 등은 일본어와 영문 명칭을 함께 추적한다. 한국어 표기 개선을 이유로 세이브의 종족·이름·파일 키를 바꾸지 않는다.

## 기술 경계와 검사

- 게임 VM의 CP932 바이트, 변수, 저장 형식, 난수, 파일 경로를 번역 작업으로 변경하지 않는다. UTF-8 한국어는 **표시 계층**에서만 사용한다.
- 플레이어 이름, 입력 중인 텍스트, 경로, 명령어, 서버 식별자, 세이브 슬롯 이름은 자동 번역하지 않는다.
- `%s`, `%d`, `\\1`, `\\#`, `\\s`, `\\n`, 색상 코드, `★`, `☆`, 키 표시 `[c]`, 수치·단위·부호는 의미를 확인하고 보존한다. 구판 사전의 `\\#`와 최신 런타임 포맷을 같은 문법으로 가정하지 않는다.
- 항목별로 원문 버전·파일·행·문맥, 번역 출처·라이선스, 검수 결과를 남긴다. 단순한 리터럴 일치는 실제 화면 번역률이 아니다.
- `review_status=reviewed`만 런타임 후보로 사용한다. `context_required`는 조용히 적용하지 않는다. 동일 원문에 다른 번역이 있으면 빌드 단계에서 충돌을 보고한다.
- 검수 순서: 용어 일관성 → 원문 의미·화자 → 효과와 수치 → 조사와 어순 → 실제 화면 줄바꿈·가독성. 대화창·인벤토리·HUD·메시지 로그의 너비가 다르므로 문자 수만으로 완료 판정하지 않는다.
- 번역 결과를 다시 조사할 수 있도록 미번역 표시 문자열은 별도 사용자 작업 폴더에 수집한다. 사용자 입력·개인 정보는 번역 코퍼스로 자동 전송하지 않는다.

## 출처별 사용 범위

`community-reviewed.json`은 Elona Wiki의 「한글패치 모음」을 2.335와 대조하여 수정한 번역 데이터이며 **CC BY-SA 3.0**으로 제공한다. 원문 URL·이름이 표시된 기여자·사본 해시·수정 사실은 각 항목의 `origin`과 `review_reason`에 있다. 이 고지는 호스트 코드·게임 원본·번들 에셋의 라이선스를 바꾸지 않는다. 자세한 근거와 알려진 제한은 `source-manifest.json` 및 `docs/KOREAN_SOURCES.md`를 참조한다.

옛 `ko.txt` 0.5.0은 공개 재사용 조건을 확인하지 못했다. 원본·전체 번역 메모리는 `.cache/`와 `work/`에만 둔다. 해당 문장을 독자 번역으로 표기해 공개하는 식의 출처 세탁을 하지 않는다. 고유명·짧은 일반 용어를 비교한 사실과 긴 문장의 재사용을 구별한다.
