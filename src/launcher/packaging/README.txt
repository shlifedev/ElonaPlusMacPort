ElonaPlus Native {version}
==========================

Play ElonaPlus 2.335 natively. The original game content is unchanged;
the only addition is an optional Korean localization.

You need your own copy of ElonaPlus 2.335
-----------------------------------------
This package contains the native engine, the prebuilt game code and the
Korean translation. It does NOT contain the game's graphics, music, sound
effects or maps. On first launch, select your ElonaPlus 2.335 folder (the
one that contains elonaplus.exe). That folder is only read, never changed.

Saves and settings live in:
  macOS:   ~/Library/Application Support/ElonaPlus Native/
  Windows: %APPDATA%\ElonaPlus Native\

macOS: the app is not notarized. On first launch, right-click (or
Control-click) ElonaPlus.app and choose Open, then confirm.

This is an experimental build. Long play sessions are not fully verified.
Project page: https://github.com/shlifedev/ElonaPlusMacPort
