# ElonaPlus Native

맥이랑 윈도우에서 ElonaPlus 2.335를 그냥 켜서 하고 싶어서 시작한 프로젝트입니다.
Wine이나 Rosetta 없이, 원본 게임 내용은 그대로 두고 실행 환경만 네이티브로 옮기고 있어요.

## 지금 상태

아직 실험 단계예요. 새 게임 시작, 맵 이동, 저장하고 다시 불러오기까지는 맥과 윈도우 둘 다에서 확인했지만,
오래 붙잡고 플레이해 본 검증은 부족합니다. 버그를 만나면 알려 주세요.

한국어 번역도 조금씩 진행 중이에요. 캐릭터 생성, 초반 대화, 인벤토리, 주요 퀘스트 정도는 한국어로 볼 수 있습니다.

## 해 보기

원본 ElonaPlus 2.335가 필요합니다. 게임 파일은 이 저장소에 들어 있지 않아요.

준비가 끝난 맥 작업공간이라면 이 파일을 더블클릭하면 됩니다.

- `Play ElonaPlus.command` — 원본 그대로
- `Play ElonaPlus Korean.command` — 한국어판

처음부터 준비하는 방법(원본 배치, 복원, 빌드)은 [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)에 정리해 두었습니다.
