# ElonaPlus Native

Play the latest ElonaPlus (2.335) natively on macOS.

The original game content is left untouched. The only addition is a Korean localization — my native language.

## Download

Grab the latest build from [Releases](https://github.com/shlifedev/ElonaPlusMacPort/releases):
`.dmg` for macOS (Apple Silicon), `.zip` for Windows x64.

You need your own copy of ElonaPlus 2.335. The packages don't include the game's graphics, music or maps;
pick your 2.335 folder on first launch and they're read from there.

On macOS the app isn't notarized yet, so right-click it and choose **Open** the first time.

This is still an experimental build. To build it yourself, see [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).
