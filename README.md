# ElonaPlus Native

Play the latest ElonaPlus (2.335) natively on macOS.

The original game content is left untouched. The only addition is a Korean localization — my native language.

## Getting started

You need your own copy of ElonaPlus 2.335; no game files are included here.
Once the workspace is prepared, double-click `Play ElonaPlus.command` (or `Play ElonaPlus Korean.command`).
Setup and build steps are in [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).

This is still an experimental build.
