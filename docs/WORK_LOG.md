# 작업 기록

## 2026-11-18 — 최초 로컬 체크포인트

이전 작업은 Git HEAD가 없는 작업 트리에 누적되어 있었다. 사용자의 지속적인 로컬 커밋 요청에 따라 현재 관리 소스·검증 도구·문서·번역 자원을 첫 체크포인트로 기록한다. 원본 게임, 역컴파일 원문, 개인 프로필, 실행 증거와 빌드 캐시는 `.gitignore`로 제외한다. 원격으로 게시하지 않는다.

- **기반:** 원본 2.335 규칙을 내장 HSP VM과 네이티브 그래픽·파일·오디오·플러그인 호환 계층으로 실행한다. Mac/Windows 기본 생성·이동·저장/로드 근거와 남은 제한은 PLAN 및 각 구현 문서에 구분했다.
- **종료 조사:** 조작 안내 창(screen20) 닫기가 원본 onexit를 통해 전체 게임을 종료하는 것을 실제 Mac SDL 창으로 재현했다. `--auxiliary-close-hide`를 플레이 런처에 연결하고 안내 창만 닫힌 뒤 이동·인벤토리·저장·새 프로세스 로드를 확인했다. 사용자 당시 클릭 대상이 같았다는 확정은 아니다. 오류/팝업/닫기 출처와 빌드 식별 진단을 추가했다.
- **플레이 확대:** 첫 집→북부 티리스→베르니스, 메뉴·장비, 초원 전투·전리품·저장/재로드, 별도 캐릭터의 자동 경로8개 통과. 실제 키보드 장시간 플레이 완료로 표현하지 않는다.
- **번역:** 기존 패치 출처 조사, 용어집·문체 지침, 독립 DB/UI/첫 집·노른 번역을 추가했다. 공개 재사용 미확인 구판 전체 사전은 private 참고 자료로만 유지한다. 위키 파생 번역의 출처·수정·CC BY-SA 고지를 기록했다.
- **표시 구현:** 검수한 문구의 CP932→UTF-8 표시, 한글 글꼴, 모호한 키/서식/UTF-8 검증, 표시와 VM/입력·저장 문자열 분리. `gmes` 문단용 관리 소스 변환과 type48 명령은 별도 검증 중이다. 원시 복원본은 수정하지 않는다. 무번역 관리 AX와 원본의 제한 경로에서 저장154개·마지막 화면이 동일했다.
- **검사:** Mac `build/localization-check` CTest11/11 (`work/localization-rich-ctest-03.log`), catalog·문단 폭/태그·VM 원문 유지·미번역 fallback 포함. 관리 소스 변환8개 검사와 원본/재컴파일/관리 AX의 신규게임 및 저장 재로드 대조 통과. 이전 출시용 개발 Release도 팝업 수정+초기 한국어 표시 포함 CTest11/11이다. 최신 문단 코드가 그 Release에 반영되었다고 혼동하지 않는다.
- **Windows:** 최신 원본 게임 생성/저장/로드·22개 fixture는 통과했지만 gui-native-04/05의 PrintWindow 타이틀 캡처 판정은 실패했다. 렌더러 화면과 외부 캡처 차이가 남아 전체 PASS로 기록하지 않는다. 별도의 한국어 표시 fixture는 설치된 Malgun으로 실제 창 표시·VM 문자열 보존·정리 통과. 문단 확장/type48은 이 Windows 검사 범위 밖이다.

### 추가 요청 — 조사만 수행

해상도·Retina 흐릿함, OS 대화상자와 원작 비교, 새 실행 실패를 별도 Codex 에이전트가 조사한다. 이 요청으로 해상도·모달 UI·시스템 화면 모드를 변경하지 않는다. 보고서: `docs/DISPLAY_UX_RESEARCH.md`.

사용자 세션 `play-q_h9nwc4`는 프레임22, `exit3/unsupported`, `chgdisp` 호출에서 종료되었다. 팝업 기록은0이고 번역 문구 오류가 아니다. 전체 화면/화면 모드 설정 분기를 조사 중이며, 새 미구현 명령을 더미 성공으로 숨기지 않는다. 사용자 설정/세이브에는 실험하지 않는다.
