# 한국어 자료 조사와 2.335 번역 기반

조사일: 2026-11-18. 대상은 사용자가 제공한 **ElonaPlus 2.335 데스크톱판**이다. 이번 조사에서 구작 한국어 사전과 공개 위키 번역문을 실제로 읽고 현재 원문과 대조했다. 최신 Plus 전체를 지원하는 완성 한국어 패치는 확인하지 못했으며, 이것은 아래 출처를 조사한 범위의 결과다.

현재 산출물:

- [용어집](../localization/ko-KR/glossary.tsv): 일본어·영어·한국어, 구판 표기, 문맥, 원문 행, 선택 이유를 갖춘 **235개 용어**.
- [기존 번역 검수 데이터](../localization/ko-KR/community-reviewed.json): 위키 번역의 현행 리터럴 일치 **111개**를 검토. **106개 reviewed**, **5개 context_required**로 구분. 실제 static `lang` 호출에서 일본어가 한 가지로 대응하는 **76개**에는 `source_ja`도 기록.
- [스타일 가이드](../localization/ko-KR/style-guide.md): 세계관·화자·게임 기능의 번역 원칙, 용어 구별, 표시 계층 경계.
- [출처 명세](../localization/ko-KR/source-manifest.json): URL, 권리 근거와 한계, 파일 해시, 코퍼스 수량, 적용 결정.

이 수치는 **화면 번역률이나 전체 게임 번역 완료율이 아니다**. 조립된 문장, 원문 외부 파일, 장문의 대사, 화면 폭 검수는 별도로 남아 있다.

## 1. 실제로 확보한 구작 한국어 사전

[두기의 Elona (K-Tran) 재배포 게시물](https://doogie838.tistory.com/581)은 2021-01-11 게시물이다. 공개 첨부 8분할 7z의 크기는 합계 78,483,002바이트다. 게시자가 [공지한 공개 암호](https://doogie838.tistory.com/notice/1313)로 `ko.txt`, `version.txt`, `readme_ENG.txt`, `readme_JP.txt` **네 개 텍스트 파일만** 추출했다. EXE·DLL·설치 프로그램·런처·번역 후커는 추출하거나 실행하지 않았다.

파일 자체에서 확인한 사실:

| 항목 | 관측 |
|---|---|
| 사전 헤더 | `엘로나 한글화 사전 파일 20100221.01`, `ver.0.5.0` |
| 사전 인코딩·크기 | CP949, 376,366바이트, 8,440행 |
| 사전 SHA-256 | `4a6bd1b558a2bb2df4d39d9addc570eccb16f5a5302c90dcc1da9130fed2c46a` |
| 동봉 version 첫 항목 | 원작 `1.16 reloaded fix 2` |
| 번역 형식 | 영어 키=한국어 값, 정규식·인수 치환·섹션 우선순위 포함 |
| 후보 행 / 고유 영어 키 | 7,303 / 6,651 |
| 같은 영어 키에 서로 다른 한국어 값 | 96개 키 |
| 2.335 HSP 문자열 리터럴과 정확히 같은 키 | 1,921개 고유 키, 중복 포함 2,353행 |

재배포 날짜를 게임·번역 버전으로 해석하지 않는다. 오래된 원작 한국어 사전이며, ElonaPlus 2.335용 패치라는 근거는 없다. 동봉 사전에서 한국어 번역자의 재배포·수정 허락을 확인하지 못했다. 블로그의 CC BY-NC-ND 표기는 게시물의 표기이며 **사전·게임·첨부물 전체의 허가로 확장하지 않는다**. 재배포자를 원 번역자로 단정하지 않는다.

따라서 이 사전은 현재 개인 검수용 참고/TM으로 보존한다. 긴 번역문을 공개 런타임 데이터에 일괄 편입하지 않았다. 인명·지명 등 짧은 용어 비교와 문장 재사용을 구별한다.

로컬 위치:

- `.cache/localization/doogie-elona-k-2021/download-manifest.json`: 다운로드 URL·크기·SHA-256.
- 같은 폴더의 `archive-list.txt`, `text/`: 목록과 추출한 네 텍스트.
- `work/localization/legacy-ko.tm.json`: 원문·번역·사전 행이 있는 전체 후보.
- `work/localization/legacy-current-exact.tm.json`: 현재 리터럴과 일치하는 후보.

## 2. 공개 위키 번역문과 재사용 조건

[Elona Wiki 한국어 「한글패치 모음」](https://elona.fandom.com/ko/wiki/%ED%95%9C%EA%B8%80%ED%8C%A8%EC%B9%98_%EB%AA%A8%EC%9D%8C)은 번역 제안·수정이 모인 페이지다. 본문에 카파·노힐부득의 기여 영역과 Evildragon의 교정이 표시되어 있다. 이 이름들은 보이는 기여자이며 전체 편집 이력의 저자 목록이라고 주장하지 않는다.

권리 근거는 [Fandom 공식 Help:Licensing](https://community.fandom.com/wiki/Help:Licensing)의 기본 텍스트 **CC BY-SA 3.0** 규정과 [같은 한국어 위키 대문](https://elona.fandom.com/ko/wiki/%EB%8C%80%EB%AC%B8)의 CC-BY-SA footer다. 수집된 번역 페이지 본문에는 다른 조건을 선언한 예외가 보이지 않았다. 공식 도움말은 원문 문서 URL을 통한 귀속과 수정 사실 표시를 설명한다.

**확인 한계:** 직접 HTML/API/편집 이력은 접근 오류·403·robots 제한이 있었고, 검색 색인에서 읽을 수 있는 본문을 사용했다. 색인 표시는 수집 시점보다 약 5개월 전 수집이다. 특정 최신 revision ID나 직접 해당 문서 footer를 읽었다고 주장하지 않는다. `revision_id=null`, 수집 방식, 원문 URL, 사본 SHA-256을 그대로 기록했다. 공개 전에 revision 확인을 다시 할 수 있지만 현재 값을 지어내거나 원 저자 표기를 삭제하지 않는다.

수집 본문에서 영어=한국어 후보 **340행 / 336고유 키**를 읽었다. 현재 HSP 리터럴과 일치하는 것은 **114행 / 111고유 키**다. 이를 2.335의 일본어·영어 문맥과 대조해 `community-reviewed.json`에 기록했다. **5개 의미 충돌 키는 전역 적용 제외**다. 나머지도 한글화 완료판이 아니라 표시 계층에서 실제로 일치할 때 사용할 수 있는 검수 데이터다.

이 파일의 위키 기반 번역 및 수정 데이터는 [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/)으로 제공한다. 각 항목의 `origin`에 원문 URL, 기여자 표기, 수집 해시, 라이선스를 두고 `review_reason`으로 변경을 알린다. 이 조건은 **해당 번역 데이터**에 적용하며 호스트 코드, 원본 게임, 그림·음악·폰트의 권리를 바꾸지 않는다.

## 3. 현행 원문 대조에서 발견한 문제

기존 번역을 가능한 한 활용하되, 영어 키 일치만으로 자동 채택하면 다음과 같은 오역이 생긴다.

| 영어 키/문제 | 기존 또는 단순 번역의 위험 | 현재 처리 |
|---|---|---|
| `Welcome traveler, I've been looking for you.` | 구판 인사말이 최신 일본어의 종족별 장비 부위 제한 설명과 대응 | 일본어 내용으로 교정 |
| `Vanish` | 소멸로 번역하면 기술의 기능이 달라짐 | 일본어 `退却`에 따라 퇴각 |
| `It's electrified.` | 기존 번역은 전력을 공급해야 한다는 뜻 | 전기를 띤 돌로 교정 |
| `gain attribute` | 능력 획득을 기술 획득으로 혼동 | 능력 획득 |
| `cure corruption` | 일반 부패 치료로 오해 | item 559의 에테르 항체 포션을 확인, 이름 부분만 에테르 항체 |
| `Weight` | 체중과 물품 무게가 같은 영어 키 | 문맥 필요, 전역 적용 제외 |
| `Come on!` | 일본어의 감탄·웃음·도발이 같은 영어 키 | 문맥 필요, 전역 적용 제외 |
| `It's nothing.` | 취소 선택지와 답례가 같은 영어 키 | 문맥 필요, 전역 적용 제외 |
| `beetle` | 일반 벌레와 헤라클레스 고유 적 이름이 같은 영어 키 | 문맥 필요, 전역 적용 제외 |
| `Attack circle` | 일반 인접 공격과 경직을 주는 다른 기술 설명이 동일 | 문맥 필요, 전역 적용 제외 |
| Juere / Jure | 구판은 쥬아·주아·쥬어 등이 혼재 | 주아족과 치유의 주아로 문맥 구분 |
| Yerles / Eulderna | 같은 사전 안의 표기 흔들림, 일본어 음역과 영문 음역 차이 | 이에르스·에우데르나를 대표 표기로 유지하고 옛 표기를 별칭 기록 |

기존 사전의 대사는 화면 행 단위로 나뉜 경우가 많다. 일부는 좌우가 잘못 대응하거나 문맥상 원문에 없는 정보를 덧붙였다. 문자열을 재정렬하거나 정규식을 최신 VM에 직접 주입해 해결하지 않는다. 명확한 문맥 ID, 전체 문장, 실제 화면을 함께 검수한다.

## 5. 재현과 다음 작업

입력 원문은 `work/decompiled/2.335-reference/start.hsp`(CP932), SHA-256 `c3b02e2d2d3b1e5ffb659c8412b017a20a20e9b25e88b2f1a7cedfe986069f55`다. 원본 게임 폴더와 ZIP은 이 조사에서 변경하지 않았다. 검색 사본과 다운로드 파일은 `.cache/localization`, 변환·대조 결과는 `work/localization`에만 있다.

실행한 재현 단계:

1. 명세의 공개 URL을 읽고 텍스트·첨부 파일을 캐시에 저장, SHA-256 기록.
2. `7zz l -slt .cache/localization/doogie-elona-k-2021/ElonaK_Win.7z.001`로 목록 확인.
3. 게시자의 공개 암호를 사용해 위 네 텍스트만 `7zz x`로 추출.
4. CP949 사전을 엄격히 디코딩하고 주석을 제외한 `영어=한국어`를 분리. 중복·충돌은 보존.
5. 2.335 CP932 소스의 인용 문자열과 정확히 대조. 이것은 HSP 파서나 전체 대사 카탈로그가 아니므로 후보 탐색으로만 사용.
6. static `lang(JP, EN)`과 주변 분기를 사람이 대조하여 기존 번역의 의미·기능·화자·명사를 검수.
7. JSON 구문, 항목 수, 키 중복, UTF-8/NFC, 원문 참조 행을 확인. 화면 줄바꿈과 실제 출력 여부는 런타임 통합 담당의 실행 검사로 확인해야 함.

다음에는 `data/exhelp.txt`의 일본어/영어 블록, packed scene, 아이템 이름 조립, 캐릭터·신·퀘스트 대사를 문맥별로 추출한다. 먼저 플레이에 꼭 필요한 캐릭터 생성·조작 도움말·집/초반 대화·인벤토리·저장/불러오기를 번역하고 화면을 확인한다. 모르는 문장을 기존 한글 사전에서 무단으로 가져온 뒤 독립 번역으로 표기하지 않는다. 공개 재사용 근거가 있는 항목은 출처와 동일 조건을 유지하고, 없는 범위는 현재 사용자가 제공한 원문을 직접 번역한다.
